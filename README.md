# CALISTHENICS — Training Tracker

Aplicativo web instalável (PWA) para acompanhar treinos de calistenia em casa.

## Publicar com GitHub Pages
1. Abra **Settings → Pages** neste repositório.
2. Em **Build and deployment**, escolha **Deploy from a branch**.
3. Selecione a branch **main** e a pasta **/(root)**.
4. Clique em **Save** e aguarde a publicação.

Depois, abra:
https://kauagdacosta-blip.github.io/calisthenics-tracker/

## Instalar no Android
Abra o endereço publicado no Chrome, toque no menu ⋮ e escolha **Instalar app** ou **Adicionar à tela inicial**.

Os registros e anotações ficam salvos localmente no navegador/aparelho e não sincronizam automaticamente entre dispositivos.
